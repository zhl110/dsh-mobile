
实测了一遍这台机器的环境，先说结论：**它不是一台“装了 Ubuntu 的电脑”，而是在 Android 手机上跑的一个 Ubuntu 24.04 容器**（`/` 是 `dm-74`，`/phone` 就是手机真实存储，里面能看到应用的数据目录），我是 root，但**完全没有任何 Android 接口**。所以缺的东西分两类。

## A. 真正做不到的（环境硬限制，装什么也补不上）

| 能力                          | 实测情况                                                                                                                                                                                                                                                                                                                                             |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **图形界面 / 操作屏幕** | `DISPLAY` 空、无 X/Wayland socket、无浏览器引擎。不能截图、点击、自动化 GUI                                                                                                                                                                                                                                                                        |
| **渲染网页 JS**         | 只能抓 HTML 原文，`web_fetch` 拿不到 JS 渲染后的内容，不能登录/点按钮                                                                                                                                                                                                                                                                              |
| **Android 系统能力**    | `/system/bin` **整个不存在**：`getprop / am / pm / dumpsys / input / screencap` 全部没有。→ 不能发通知、读剪贴板、调摄像头麦克风、装 APK、控制 App、读电量传感器                                                                                                                                                                          |
| **文件沙盒**            | 内核禁止创建 namespace（`bwrap` 报 `Invalid argument`），无 Landlock。→ `workspace-write` 模式在这台机上**直接不可用**，只能 `danger-full-access`，等于没有隔离                                                                                                                                                                       |
| **系统服务 / 自启**     | PID 1 是 Android `init`，无 systemd。后台任务只能靠 dsh 自己的 job，进程挂了就没了，不能开机自启                                                                                                                                                                                                                                                   |
| **GPU 加速**            | 有 `/dev/kgsl-3d0` 节点但无 GL 驱动栈，跑不了需要 GPU 的东西                                                                                                                                                                                                                                                                                       |
| **部分网络**            | `registry.npmjs.org`、`pypi.org`、`files.pythonhosted.org`、`api.anthropic.com`、`api.github.com`、`raw.githubusercontent.com` **全部解析/连接失败**；`github.com` 直连不通（`codeload.github.com` 反而 301 通）。能用的只有 `registry.npmmirror.com`、清华/阿里镜像、`api.deepseek.com`。DNS 本身也不稳，8.8.8.8 经常超时 |

## B. 没装但能补的（`apt` 实测可用）

系统是**极简 Ubuntu 24.04 arm64，dpkg 只有 124 个包**。实测 `apt-get update` 成功（走清华 ubuntu-ports 镜像），`python3` 3.12.3 可装。

现在**全都没有**的：

```
python3 python pip3 git gcc g++ make cmake rustc go java
docker podman sqlite3 ffmpeg convert(magick) pdftoppm
libreoffice soffice pandoc tesseract
ssh rsync wget unzip zip file tmux
```

> `docker/podman` 即使装了也跑不起来（没 namespace），`tmux` 装了才有 `dsh-tool-terminal` 那套。

## C. 落到“我具体哪件事干不了”

- **文档**：docx/xlsx/pptx 能生成（office 插件 + wasm 内核）；但 PDF 转图、渲染预览没有 `pdftoppm`
- **图片**：能**看**（`read_image`），不能生成/裁剪/转格式（无 PIL、无 ImageMagick）
- **音视频**：无 `ffmpeg`，不能转码、抽帧、看视频
- **压缩包**：无 `unzip`/`zip`，只能改用 node 或先装
- **浏览器那侧的事**：登录、填表、翻页这类只能你在页面上点，我做不了
- **手机那侧的事**：帮你点屏幕、读通知、拍照、连蓝牙，一律不行

## D. 不算限制的部分

硬件其实不弱：**8 核、23 GB 内存（可用 7.5 G）、341 G 空闲磁盘**。长任务、大文件、并行 subagent 都没问题。卡的是 A 类那几项，不是性能。
